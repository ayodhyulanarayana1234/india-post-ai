# India Post AI

AI-powered financial needs identification and campaign optimization system for India Post.

## Project Goal

The system aims to identify the financial and insurance needs of different geographic and demographic populations and recommend:

- What financial or insurance product should be promoted
- Where it should be promoted
- When it should be promoted
- Which population segment should be targeted
- How resources should be allocated
